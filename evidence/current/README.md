Two actual fresh runs of the complete 24-stage scientific plan, normal and
optimized CPython 3.12.14, were performed on the local Windows host recorded in
`environment.json`. They each pass 96 discovered unit tests and six standalone
ordered-admission methods. Modes do not double the number of distinct systems.
The complete legacy and staged campaigns and seven independent-classifier
parts are executed, not copied historical successes.

`comparison.json` records equality of 132 deterministic files across the two
modes and 93 non-test scientific files against the original historical results.
The old 81-test summary and every original `results/` file are preserved.

Each mode directory contains the full fresh scientific outputs, complete named
inputs/proofs, 135 complete-cost timing rows for the nine existing named cases,
actual child argv/return codes, and raw stdout/stderr. `driver-resources.json`
binds consumed source/input hashes. Timings and memory are observations, not
deterministic equality fields. Public absolute private-path prefixes are
redacted to `<audit-workspace>`, `<candidate>`, and `<python>`; unredacted records
are retained privately. Private resumability markers are not redistributed.

The explicit Windows portable option runs the same scientific computations
with sequential children and 240-second child wall timeouts. POSIX CPU and
address-space caps and cumulative child CPU/RSS are unavailable and null.
Own-process CPU/wall time and peak working set are actual Windows measurements.
This is not a resource-limit emulator or a native BuildIt/Nexis deployment.

The saturated route accepts S01/S07/S09/S11, falls back to exact positive
evidence for S08, and retains S02/S03/S04/S10 terminal forks. GP/CC are checked
globally; syntax-safe guard checks remain active under `-O`. The ordinary direct
checker receives the same tables but trusts search. Both proof routes provide
the same confluence/positive terminal-semantic guarantee; a negative fork does
not prove all-terminal semantic equivalence.

The modular route is slower in every named case in both modes. It transmits
smaller proofs for S01/S09 but larger proofs for S07/S11. These finite results
support factoring graph obligations, not a general performance or novelty claim.
